Privacidad

Resumen del tratamiento de datos de la extensión actual y este sitio. La política completa de la extensión está disponible en inglés y coreano.

Actualizado el 8 de octubre de 2026

Procesamiento en el dispositivo

Las URL compatibles y una geometría DOM limitada se procesan localmente. La versión general no envía las URL visitadas a la API de enlaces de producción.

Almacenamiento y control

Ajustes, idioma, selección de comparación e identificadores afiliados públicos quedan en el almacenamiento local de la extensión. El procesamiento temporal usa sesión o memoria. Puedes desactivar sugerencias, limitar permisos o desinstalar para eliminar los datos.

Destinos externos

Al pulsar un enlace afiliado configurado, el identificador público y el destino pueden enviarse al comercio o red. Se aplican sus políticas. No se solicitan contraseñas ni datos de pago, ni se usan bases de historial o SDK analíticos.

Este sitio

Sin analítica, rastreadores publicitarios ni formularios. GitHub Pages puede procesar metadatos de solicitudes para servir el sitio. El idioma puede guardarse en el navegador. Al enviar un correo se comparte su contenido con RushLabs.
