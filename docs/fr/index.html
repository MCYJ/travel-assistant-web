03 / Pour les partenaires

Un canal de recommandation transparent.

Pour les réseaux et annonceurs qui examinent le trafic des extensions. L’autorisation de chaque programme est vérifiée avant l’activation des liens monétisés.

✓

Visites initiées par l’utilisateur

Aucune redirection automatique ni application de liens affiliés en arrière-plan sur les sites réels.

✓

Commission clairement indiquée

Les liens affiliés configurés sont identifiés. Les achats peuvent rémunérer l’exploitant du compte configuré.

✓

Respect de l’attribution existante

Les paramètres publisher détectés sont préservés. Aucun cookie n’est lu.

✓

Activation après accord

Sans configuration approuvée, des liens ordinaires sont utilisés. Aucune remise ni cashback vérifiés ne sont activés actuellement.

Disponible pour examen technique.

Un build de développement est disponible sur demande. La soumission au store attend des avantages vérifiés, l’accord des programmes et l’examen final. Audience, conversions et revenus ne sont pas vérifiés.
