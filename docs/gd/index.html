Installation

Chrome · Edge · Brave · Opera · Whale

Download and unzip the file. Open your browser’s extensions manager, enable Developer mode, then choose Load unpacked and select the extracted folder. Allow access only to sites you want to use.

Firefox

Unzip the file. Open about:debugging, choose This Firefox → Load Temporary Add-on, and select manifest.json. This temporary installation ends when Firefox closes.

Safari

Safari requires a signed native app. The ZIP downloads on this page do not install a Safari extension. Contact us for Safari distribution information.
