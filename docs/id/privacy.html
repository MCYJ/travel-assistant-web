Diproses di perangkat

URL halaman yang didukung dan geometri DOM terbatas diproses secara lokal. Versi umum tidak mengirim URL penjelajahan ke API tautan produksi.

Penyimpanan dan kontrol

Pengaturan, bahasa, pilihan perbandingan dan ID afiliasi publik tetap di penyimpanan lokal ekstensi. Pemrosesan sementara memakai sesi atau memori. Saran dapat dinonaktifkan, akses situs dibatasi, dan penyimpanan dihapus dengan mencopot ekstensi.

Tujuan eksternal

Klik pada tautan afiliasi yang dikonfigurasi dapat mengirim ID publik dan tujuan ke pedagang atau jaringan. Kebijakan mereka berlaku. Tidak meminta kata sandi atau data pembayaran, tidak ada basis riwayat atau SDK analitik.

Situs ini

Tanpa analitik, pelacak iklan atau formulir kontak. GitHub Pages dapat memproses metadata permintaan untuk melayani situs. Bahasa pilihan dapat disimpan di browser. Email yang dikirim membagikan isinya kepada RushLabs.
