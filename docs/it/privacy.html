Privacy

Panoramica del trattamento dei dati dell’estensione attuale e di questo sito. La politica completa dell’estensione è disponibile in inglese e coreano.

Aggiornato l’8 ottobre 2026

Elaborazione sul dispositivo

Gli URL supportati e una geometria DOM limitata sono elaborati localmente. La build generale non invia gli URL visitati all’API di link di produzione.

Archiviazione e controllo

Impostazioni, lingua, selezioni di confronto e ID affiliati pubblici restano nell’archivio locale dell’estensione. L’elaborazione temporanea usa sessione o memoria. Disattiva suggerimenti, limita gli accessi o disinstalla per rimuovere i dati.

Destinazioni esterne

Un clic su un link affiliato configurato può inviare l’ID pubblico e la destinazione al commerciante o alla rete. Si applicano le loro politiche. Nessuna richiesta di password o dati di pagamento, nessun database di cronologia o SDK analitico.

Questo sito

Nessuna analisi, tracker pubblicitario o modulo di contatto. GitHub Pages può elaborare metadati delle richieste per fornire il sito. La lingua può essere salvata nel browser. Le email inviate condividono il contenuto con RushLabs.
