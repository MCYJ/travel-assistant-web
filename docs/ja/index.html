pikviaは「選ぶ」を意味する“pick”と「〜を通じて」を意味する“via”を合わせた名前です。関連サービスを見つけ、次の訪問先は自分で選びます。

03 / パートナー向け

透明性のある送客経路。

拡張機能からの流入を審査するネットワークと広告主向けの資料です。収益化リンクは各プログラムの許可を確認してから有効にします。

✓

ユーザーのクリックが起点

実際のサイトで自動転送やバックグラウンドのリンク適用は行いません。

✓

報酬の明確な表示

設定済みの提携リンクを画面で示します。購入により設定されたアカウントの運営者に報酬が生じる場合があります。

✓

既存の帰属情報を保護

検出したpublisherパラメータを保持し、Cookieは読み取りません。

✓

承認後に有効化

承認済み設定がなければ通常リンクを使用します。検証済みの割引・キャッシュバックは現在ありません。

技術審査に対応します。

開発ビルドはお問い合わせください。検証済み特典、プログラム承認、最終確認までストア提出は保留中です。利用者数・コンバージョン・収益は未検証です。
