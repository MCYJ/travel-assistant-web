プライバシー

プライバシーとデータ

サポートされているサイトの現在の URL と限定されたレイアウト情報がデバイス上で処理されて、ページが分類され、UI が配置されます。設定と公開アフィリエイト ID はローカル ストレージに残ります。自動処理される URL ハッシュとタイムスタンプは、ブラウザー セッションの間持続します。重複チェックは 30 分間有効です。閲覧した URL は分析サーバーに送信されず、履歴として蓄積されません。アフィリエイト リンクをクリックすると、設定された公開アフィリエイト ID が宛先サイトまたはアフィリエイト ネットワークに公開される場合があります。保持、削除、サードパーティによる取り扱いについては、公開プライバシー ポリシーを参照してください。クリックしてアフィリエイトオファーを検査すると、選択したサービスとパートナーID、ブラウザの種類、適用範囲のみがCloudflareワーカーに送信されます。オペレーターが管理するリンクとクーポンの構成は、エンドユーザーのデータとは別に保存されます。

パートナー設定

ローカル自動リンクは、ホームページと検証済みの公開 KKday、Tiqets、Airalo、Saily、Yesim、および WeGoTrip 製品をサポートします。ホームページの検索では URL は送信されません。製品の URL とホワイトリストに登録されたパッケージのオプションまたは日付は、選択された製品をサーバー履歴なしで保持するために Worker と Travelpayouts に一時的に送信されます。検索、アカウント、カート、チェックアウト、不明なクエリ、および既存の帰属は除外されます。サイトは独自の Cookie を設定する場合があります。リダイレクトは帰属を証明するものではありません。

アフィリエイトリンク

アフィリエイト リンクを介して予約または購入すると、設定されたアフィリエイト アカウント所有者に手数料が発生する場合があります。

GitHub Pages

解析、広告トラッカー、問い合わせフォームはありません。GitHub Pagesは配信に必要なリクエスト情報を処理する場合があります。選択言語はブラウザに保存される場合があります。メール送信時の内容はRushLabsに届きます。
