Chrome · Edge · Brave · Opera · Whale

ZIP 파일의 압축을 풀어 주세요. 브라우저의 확장 관리 화면에서 개발자 모드를 켠 뒤 ‘압축해제된 확장 프로그램 로드’로 해당 폴더를 선택하세요. 사용할 사이트에만 접근을 허용해 주세요.

Firefox

압축을 풀고 about:debugging에서 ‘이 Firefox → 임시 부가 기능 로드’를 선택한 뒤 manifest.json을 열어 주세요. 임시 설치는 Firefox를 종료하면 해제됩니다.

Safari

Safari는 서명된 앱을 설치하는 방식입니다. 이 페이지의 ZIP 파일은 Safari 설치 파일이 아닙니다. Safari 배포에 관한 내용은 문의해 주세요.
