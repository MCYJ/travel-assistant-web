2026년 10월 8일 갱신

기기 내 처리

지원 페이지 URL과 제한된 DOM 위치·크기를 기기에서 처리해 사이트를 인식하고 UI를 배치합니다. 현재 일반 빌드는 방문 URL을 운영 링크 API에 보내지 않습니다.

저장과 제어

설정·언어·비교 선택·공개 제휴 ID는 확장 로컬 저장소에 보관합니다. 임시 처리는 세션 또는 백그라운드 메모리를 사용합니다. 추천을 끄거나 사이트 접근을 제한할 수 있고 확장 삭제 시 저장소가 제거됩니다.

외부 사이트 이동

설정된 제휴 링크를 클릭하면 공개 제휴 ID와 목적지가 판매자 또는 네트워크에 전달될 수 있으며 해당 정책이 적용됩니다. 비밀번호·결제정보를 요청하지 않고 방문 기록 DB나 분석 SDK를 운영하지 않습니다.

이 웹사이트

분석 도구·광고 추적기·문의 양식이 없습니다. GitHub Pages는 사이트 제공을 위해 요청 메타데이터를 처리할 수 있습니다. 선택 언어는 브라우저에 저장될 수 있습니다. 이메일 버튼은 메일 앱을 열며 발송 시 내용이 RushLabs에 전달됩니다.
