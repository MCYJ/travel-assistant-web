개인정보와 데이터

지원 사이트의 현재 URL과 일부 화면 배치 정보를 기기에서 처리해 페이지 분류와 추천 UI에 사용합니다. 설정과 공개 제휴 ID는 로컬에 보관합니다. 자동 처리의 URL 해시와 시간은 브라우저 세션에만 보관하며 판단 유효기간은 30분입니다. 방문 URL을 분석 서버로 전송하거나 방문 이력을 축적하지 않습니다. 제휴 링크를 누르면 설정된 공개 제휴 ID가 방문 사이트 또는 해당 제휴 네트워크로 전달될 수 있습니다. 자세한 보관·삭제·제3자 처리 내용은 공개 개인정보처리방침을 확인하세요. 제휴 혜택 확인을 클릭하면 선택한 서비스·파트너 ID, 브라우저 종류와 적용 범위만 Cloudflare Worker로 전달합니다. 운영자가 관리하는 링크·쿠폰 설정은 최종 사용자 데이터와 분리해 보관합니다.

설정

로컬 자동 적용은 지원 홈페이지와 KKday·Tiqets·Airalo·Saily·Yesim·WeGoTrip의 확인된 공개 상품 페이지에서 동작합니다. 홈 조회에는 URL을 보내지 않습니다. 상품 페이지는 상품 주소와 허용된 상품 옵션·이용일을 Worker와 Travelpayouts에 전달하여 같은 상품으로 연결합니다. 주소를 서버에 기록하지 않으며 검색·계정·장바구니·결제·알 수 없는 쿼리·기존 제휴 링크는 제외합니다. 사이트가 자체 쿠키를 설정하며 전환만으로 귀속 성공을 뜻하지 않습니다.
