03 / 合作伙伴

透明的推荐流量渠道。

为审核浏览器扩展流量的联盟网络和广告主提供信息。启用变现链接前，先确认每个项目的使用许可。

✓

用户主动点击

在真实网站上不会自动跳转或在后台应用联盟链接。

✓

明确披露佣金

已配置的联盟链接会在界面标识。购买可能为已配置账户的运营方带来佣金。

✓

保护现有归因

保留检测到的publisher参数，不读取网站Cookie。

✓

批准后启用

未有已批准配置时使用普通链接。目前未启用经验证的折扣或返现。
